# 휴대폰·태블릿에서 앱처럼 쓰기 (설치형 페이지 안내)

이 안내서는 전통발효체험관을 휴대폰이나 태블릿의 **홈 화면에 앱처럼** 올려 두고 쓰는 방법을 설명해요.
선생님, 보호자, 운영자가 읽는 글이에요. 어려운 낱말은 맨 아래 「낱말 풀이」에 모아 두었어요.

## 1. 먼저 알아 둘 것

- 앱처럼 설치하는 기능은 **서버에 설치된 체험관 주소**로 열었을 때만 나와요.
  예: `https://우리학교주소/metaverse/`
- 체험관 파일(`전통발효체험관.html`)을 더블클릭해서 연 경우에는 설치 기능이 없어요. 그래도 체험은 그대로 할 수 있어요.
- 주소는 **https** 로 시작해야 해요. (학교 안의 시험용 컴퓨터에서 `http://localhost` 로 여는 경우만 예외예요.)
- 쉬운 모드(어린이 화면)에서는 설치 단추가 보이지 않아요. 설치는 어른이 해 주세요.
- 설치해도 따로 돈이 들지 않고, 체험관의 내용도 똑같아요. 홈 화면에서 바로 열리고, 주소창 없이 화면을 넓게 쓸 수 있을 뿐이에요.

## 2. 안드로이드 휴대폰·태블릿 (크롬, 삼성 인터넷)

1. 크롬이나 삼성 인터넷으로 체험관 주소를 열어요.
2. 어른 모드라면 화면 위쪽 가운데에 **📲 앱처럼 설치** 단추가 나와요. 누르면 휴대폰이 "설치할까요?" 하고 물어요. **설치**를 눌러요.
3. 단추가 안 보이면 브라우저 메뉴(오른쪽 위 점 세 개 **⋮**)를 열고 **앱 설치** 또는 **홈 화면에 추가**를 눌러요.
4. 홈 화면에 옹기 항아리 그림의 **전통발효체험관** 아이콘이 생겨요.

단추 옆의 **✕** 를 누르면 그 기기에서는 단추가 더 나오지 않아요. 그래도 3번처럼 메뉴로 설치할 수 있어요.

## 3. 아이폰·아이패드 (사파리)

아이폰과 아이패드에는 설치 단추가 나오지 않아요. 대신 이렇게 해요.

1. **사파리**로 체험관 주소를 열어요. (다른 브라우저에서는 이 메뉴가 없을 수 있어요.)
2. 아래쪽(아이패드는 위쪽)의 **공유 단추**(네모에서 위로 화살표가 나온 모양)를 눌러요.
3. 목록을 조금 내려서 **홈 화면에 추가**를 누르고, 오른쪽 위 **추가**를 눌러요.
4. 홈 화면에 옹기 항아리 아이콘이 생겨요.

iOS 16.4 이후 버전에서 가장 잘 돼요. 그보다 오래된 기기에서는 아이콘은 생기지만, 아래 4번의 "인터넷이 없을 때" 화면이 나오지 않을 수 있어요.

## 4. 컴퓨터 (크롬, 엣지)

주소창 오른쪽 끝에 작은 **설치 아이콘**(모니터에 아래 화살표)이 보여요. 눌러서 **설치**를 고르면 바탕 화면과 시작 메뉴에 체험관이 생겨요. 체험관 화면 위쪽의 **📲 앱처럼 설치** 단추를 눌러도 돼요.

## 5. 인터넷이 없을 때 되는 것과 안 되는 것

설치한 뒤 한 번이라도 인터넷이 될 때 체험관을 열었다면, 기기가 체험관 화면을 기억해 두어요.

**인터넷이 끊겼을 때 아이콘을 누르면** 「인터넷 연결을 기다리고 있어요」라는 조용한 화면이 나와요. 단추가 두 개 있어요.

- **다시 연결해 보기** — 와이파이나 데이터를 켠 뒤 누르면 평소처럼 열려요.
- **인터넷 없이 둘러보기** — 기억해 둔 체험관을 인터넷 없이 열어요. 이때는 "로컬 모드"예요.
  - 마을 구경, 농사·발효 체험, 학습 카드처럼 이 기기 안에서 되는 것은 할 수 있어요.
  - 그동안 한 일은 **이 기기에만** 저장돼요. 계정에는 올라가지 않아요. 나중에 인터넷이 되어도 자동으로 합쳐지지 않아요.

**인터넷이 있어야만 되는 것**: 로그인과 계정 저장, 다른 친구와 함께 있기·채팅, 순위, 결제, 강의실 영상, 신고·문의, 분양 신청과 관리, 관리자 사이트. 이런 것은 인터넷이 돌아온 뒤 **다시 연결해 보기**로 열어서 해 주세요.

기기는 체험관 화면(페이지 한 장, 그림 몇 장, 안내 화면)만 기억해요. 아이들의 기록, 사진, 비밀번호 같은 것은 기억해 두지 않아요. 서버와 주고받는 내용은 늘 서버로 바로 가요.

## 6. 새 버전이 나왔을 때

운영자가 서버의 체험관을 새 버전으로 바꾸면, 다음에 인터넷이 될 때 열면서 새 화면을 받아요. 기기가 기억해 둔 예전 화면은 저절로 지워져요. 따로 할 일은 없어요.

## 7. 지우고 싶을 때

- **안드로이드**: 홈 화면의 아이콘을 길게 누르고 **삭제** 또는 **제거**를 눌러요.
- **아이폰·아이패드**: 아이콘을 길게 누르고 **앱 제거 → 홈 화면에서 제거** 또는 **앱 삭제**를 눌러요.
- 기억해 둔 화면까지 지우려면 브라우저 설정의 **사이트 데이터 삭제**에서 체험관 주소를 지워요.

## 8. 운영자가 알아 둘 것

- 배포 zip의 `metaverse/` 폴더에 설치형 페이지 파일이 함께 들어 있어요. 새로 만들 것은 없어요.
  - `manifest.webmanifest` — 앱 이름, 색, 아이콘을 적은 쪽지
  - `sw.js` — 서비스 워커. 체험관 화면을 기억해 두었다가 인터넷이 끊겼을 때만 꺼내 보여 줘요
  - `offline.html` — 「인터넷 연결을 기다리고 있어요」 화면
  - `icons/` — 홈 화면 아이콘 네 장 (체험관의 옹기 항아리 그림으로 빌드할 때 그려요)
- 이 파일들은 새 버전을 빌드할 때마다 다시 만들어져요. 손으로 고치지 마세요.
- `.htaccess` 에 필요한 설정(서비스 워커가 화면을 받아 오도록 허락하는 보안 설정, 파일 종류)이 이미 들어 있어요. XAMPP 의 기본 설정(`AllowOverride All`)이면 따로 할 일이 없어요.
- **https 가 꼭 필요해요.** https 가 아닌 주소에서는 브라우저가 설치 기능과 서비스 워커를 켜지 않아요. 체험은 그래도 돼요.
- 서비스 워커는 `api/`, `admin/`(이름을 바꾼 관리자 폴더도 `.php` 이므로 같아요), `uploads/`, `data/` 와 모든 `.php` 주소에는 손대지 않아요. 로그인·저장·결제는 언제나 서버가 직접 대답해요.
- **설치 기능을 끄고 싶을 때**: `metaverse/` 에서 `sw.js` 를 지우세요. 이미 설치한 기기는 다음에 인터넷이 될 때 서비스 워커를 스스로 내려놓아요. 처음부터 만들지 않으려면 빌드할 때 `node tools/build.mjs --no-pwa` 를 써요.

## 9. 나중에 앱 스토어에 올리려면 (같은 폴더를 앱으로 감싸기)

지금 들어 있는 것은 "홈 화면에 올리는 웹 앱"이에요. 플레이 스토어나 앱 스토어에 올리려면 같은 체험관 주소를 앱 껍데기로 감싸는 작업이 더 필요해요. 개발자에게 맡길 일이에요.

- **안드로이드 (플레이 스토어)**: 신뢰할 수 있는 웹 활동(TWA, Trusted Web Activity)이라는 방식으로, 지금의 https 주소를 그대로 여는 앱을 만들 수 있어요. 도구로는 Bubblewrap 이나 PWABuilder 를 많이 써요. 필요한 것: 구글 플레이 개발자 계정, 앱 서명 열쇠, 그리고 체험관 서버의 `.well-known/assetlinks.json` 파일(앱과 주소가 같은 주인임을 밝히는 쪽지).
- **아이폰·아이패드 (앱 스토어)**: 애플은 웹 페이지만 감싼 앱을 잘 받아 주지 않아요. Capacitor 같은 도구로 체험관 폴더를 앱 안에 넣고, 휴대폰 기능(알림 등)을 조금 더해야 심사를 통과하기 쉬워요. 맥 컴퓨터와 애플 개발자 계정이 필요해요.
- **어린이 앱 규칙**: 두 스토어 모두 어린이 대상 앱에 따로 규칙이 있어요. 개인정보 처리방침 주소, 광고 없음, 바깥으로 나가는 링크와 결제 앞의 보호자 확인이 필요해요. 체험관에는 보호자 확인(어른 확인 문제)이 이미 있어요. 정책 문구는 운영자와 법률 전문가가 확인해 주세요.
- **결제 주의**: 스토어 앱 안에서 디지털 상품(속도 이용권 등)을 팔면, 스토어의 결제 규정을 따라야 할 수 있어요. 지금의 토스 결제를 앱 안에서 그대로 쓰지 못할 수 있으니, 스토어에 올리기 전에 꼭 확인해 주세요.

## 10. 들어 있지 않은 것

- 스토어에 올리는 앱 파일(안드로이드 APK·AAB, 아이폰 IPA)과 앱 서명 열쇠
- 푸시 알림(휴대폰 위쪽에 뜨는 알림)
- 인터넷 없이 한 일을 나중에 계정으로 옮기는 기능
- 인터넷이 없을 때의 로그인, 채팅, 순위, 결제, 강의 영상

## 낱말 풀이

- **https**: 주소와 주고받는 내용을 자물쇠로 잠가 보내는 방식이에요. 주소가 `https://` 로 시작해요.
- **서비스 워커**: 브라우저 안에서 체험관 화면을 기억해 두었다가, 인터넷이 끊겼을 때 대신 보여 주는 작은 도우미 프로그램이에요.
- **매니페스트**: 앱 이름, 아이콘, 색 같은 것을 적어 둔 쪽지 파일이에요.
- **로컬 모드**: 서버 없이 이 기기 안에서만 저장하며 체험하는 방식이에요.
- **캐시**: 브라우저가 기억해 둔 파일 꾸러미예요.
