# 참고 자료 (소유자 제공) — 만장대 단지

이 폴더의 그림은 소유자가 준 기획 자료예요. **빌드·자료 묶음(pack)·배포 zip에 들어가지 않아요.** 3D 단지를 만들 때 "이렇게 보여야 한다"는 기준으로만 써요.

| 파일 | 내용 | 쓰임 |
|---|---|---|
| `03-concept-main.webp` | 단지 조감도(본관, 한옥 마을, 동심원 장독대, 정자, 회랑, 회전교차로 정원, 주차장, 강과 도로, 숲이 우거진 산) | **만장대 단지(`PL_ALLOT`)의 모습 기준 — 가장 중요** |
| `04-concept-entrance.webp` | 입구 쪽 조감도(강, 돌다리, 기암절벽, 주차장과 버스, 방문자 건물) | 입구·강가·주차장 |
| `02-site-plan.webp` | 계획도(약초 스마트팜 단지, 옹기항아리 공장, 장항아리 전시 단지, 농촌형 카페·체험맛집, 주차장, 사업관리·장류 제조 체험·와인/식초 체험·교육생 숙소) | 구역의 쓰임새 |
| `01-parcels.webp` | 필지 목록과 지도(30필지, 합계 약 16,015평) | 실제 터의 크기 감각 |

규칙: 그림을 그대로 붙여 넣지 않아요(3D로 다시 만들어요). 그림 속 숫자·필지 정보는 앱 화면에 내보내지 않아요.
