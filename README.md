# 전통발효체험관 메타버스

한국 전통발효문화와 농업체험을 3D로 탐험하며 배우는 **브라우저 메타버스 체험관**입니다.
설치 없이 **HTML 파일 하나**로 실행됩니다 (Three.js 3D 엔진 내장, 인터넷 연결 불필요).

> **용어 풀이**
> - **메타버스**: 여러 사람이 아바타로 접속해 함께 돌아다니는 3D 가상 공간
> - **Three.js**: 웹브라우저에서 3D 그래픽을 그려 주는 자바스크립트 라이브러리 (WebGL 사용)
> - **WebGL**: 브라우저가 그래픽카드(GPU)로 3D를 그리게 해 주는 표준 기술
> - **단일 파일(Single-file) 빌드**: 코드·스타일·3D 엔진·글꼴을 HTML 한 파일에 모두 넣은 형태

## 1. 바로 실행하기

| 방법 | 하는 일 | 저장 위치 |
|---|---|---|
| **A. 파일 더블클릭** | `전통발효체험관.html` (또는 `metaverse/index.html`)을 Chrome·Edge·Firefox·Safari로 열기 | 이 브라우저(localStorage) |
| **B. PHP 서버 모드** | `metaverse/` 폴더를 XAMPP `htdocs`에 복사 → `http://localhost/metaverse/install.php` 로 설치(서버 PC 에서 받은 **설치 코드** 필요) → `http://localhost/metaverse/` 접속 | 서버 DB (회원가입·서버 저장·실시간 채팅/접속자) |

- B 방식의 단계별 설치는 `docs/SERVER-INSTALL-KO.md`, 자세한 설정은 `metaverse/README-SERVER.md` 를 참고하세요 (MariaDB/MySQL 또는 SQLite). 공개 인터넷에 열기 전에 `docs/SECURITY-REPORT-KO.md` 의 "1.3 지금 바로 할 일" 을 해 주세요.

## 3. 첫 체험 흐름 (약 10분)

`로그인 → 정선 만장대 전망대에서 시작(소개 영상, 누르면 건너뛰기) → 산길을 걸어 내려가기 → 발효마스터와 대화 → 작물밭 이동 → 물 주기 → 수확 → 장독대 방문 → 내 장독 발효 확인 → 교육 콘텐츠 → 퀴즈 → 작업일지 작성 → 보상 받기 → 저장 → 로그아웃 → 다시 로그인 시 그대로 복구`

## 4. 주요 기능

- **3D 월드**: 산·계곡·강, **정선 만장대 전망대**(시작 장소 · 팔각정 · 표지석 · 망원경 · 굽은 산길), 현대식 유리+한옥 지붕 체험관, 한옥·초가집·정자, 나선형 장독대, 3×2 작물밭, 허브정원, 휴식정원 — 바람에 흔들리는 풀·나무, 꽃잎·안개·햇살, 물결·빗방울, 밤 반딧불
- **아바타**: 귀여운 3등신 캐릭터, 헤어·옷·한복·가방·소품 꾸미기
- **NPC 5명 + 대화 분기**: 발효마스터·산골농부·전통사랑·장독지기·안내원
- **퀘스트**: 튜토리얼 메인 퀘스트 + 탐험·농사·발효·교육·사진·소통 퀘스트 (금빛 표식 안내)
- **농사**: 씨앗 심기 → 물 주기 → 성장(성장률·수분·건강) → 수확, 작물 10종
- **장독 발효**: 계정당 1개 배정되는 빛나는 내 장독, 된장·간장·고추장·김치·식초 (온도·습도·위생 → 품질)

## 5. 보안 요약

- **CSP(콘텐츠 보안 정책)**: 빌드가 인라인 스크립트의 해시를 계산해 허용 — 외부 스크립트·eval·인라인 이벤트 금지 (XSS 방어)
- 사용자 입력은 모두 이스케이프 또는 `textContent`로 표시, 채팅 욕설 필터(띄어쓰기·자모·l33t 우회 정규화)·도배 방지
- **어린이 개인정보 보호**: 채팅의 전화번호·이메일·주소·학교·링크를 🔒 로 가림(브라우저 + 서버 저장 전), 개인정보 같은 닉네임 거부, 쉬운 모드는 글자 입력 없음, 어른 화면 앞 보호자 확인
- 로컬 계정 비밀번호: **PBKDF2-SHA256 60만 회** + 무작위 솔트 (비밀번호 원문은 저장하지 않음), 로그인 실패 시 잠금
- 서버 모드: 비밀번호는 `password_hash`(Argon2id — PHP 7.2 에서는 Argon2i, 둘 다 없으면 bcrypt), CSRF 토큰·Origin 검사, 세션 고정 방지, 무차별 대입 잠금, **저장 데이터 치팅 검증**(보상표·서버 시간 기준, 하루 1회 보상 장부), 업로드 이미지 재인코딩
- 7단계 보안 잠금: HTTPS 강제, 모든 입력의 서버 검사, 수상한 활동 기록과 자동 차단, 관리자 센터 경로 잠금(무작위 폴더 이름·허용 주소·2단계 인증), 엔드포인트별 요청 한도, 좁힌 CORS, 보안 헤더, 결제 금액 서버 확인, DB 전용 계정과 결제 수단 정보 암호화, 노출 파일·SQL·비밀 값 자동 검사 — 공격 흉내 시험 SQLite 183/183 · MariaDB 181/181 (Apache 포함)
- 알고 남겨 둔 한계(예: 개발 환경에 PHP 7.2 가 없어 그 위에서는 문법 검사로만 확인)와 이유는 보고서 4장에 있어요
- 자세한 내용: **`docs/SECURITY-REPORT-KO.md`** (23개 항목 보고서), `server/README-SERVER.md`, `docs/HANDOVER.md` §18

> **용어 풀이** — *CSRF*: 다른 사이트가 내 로그인 상태를 몰래 이용해 요청을 보내는 공격 · *PBKDF2/Argon2id*: 비밀번호를 일부러 느리게 여러 번 해시해 추측을 어렵게 만드는 방식 · *솔트*: 같은 비밀번호라도 저장값이 달라지도록 섞는 무작위 값

## 6. 개발자용

```bash
npm install                 # three, esbuild, playwright, pretendard (빌드·테스트 도구)
npm run build               # src/ → dist/metaverse/index.html (+ PHP 서버 파일)
node tools/smoke.mjs        # 헤드리스 브라우저 자동 실행 테스트 (오류·스크린샷)
node tests/server-e2e.mjs   # 서버 보안·기능 E2E 77단계 (php -S 자동 실행, 개인정보 가림 벡터·DB 스팸 키·구독 결제 포함; 결제 단계는 TFM_TOSS_MOCK=1)
node tools/kid-audit.mjs    # 👶 쉬운 모드 화면 자동 점검 (치명 문제가 있으면 실패) — --mobile · --both · --out 파일
node tools/text-audit.mjs   # 🔤 금지 낱말 점검 — 소스·문서·빌드된 HTML 에 옛 호칭이 남아 있으면 실패 (--html 파일 · --no-html)
node tests/pii-sync.mjs --check                              # 개인정보 가림 규칙: 브라우저 ↔ 서버(pii-rules.json) 같은지
node tests/pii-client.mjs --file dist/metaverse/index.html   # 빌드된 체험관과 PHP 의 가림 결과가 똑같은지 (벡터 전체)
npm run package             # release/fermentation-metaverse.zip
npm run serve:php           # PHP 내장 서버로 서버 모드 실행 (http://127.0.0.1:8080)
# 7단계 보안 시험·검사 (전체 명령·MariaDB 로 돌리기·결과 읽는 법: docs/SECURITY-REPORT-KO.md "5. 점검 다시 해 보는 법")
node tests/security-e2e.mjs --apache   # 공격 흉내 시험 S01~S19 — dist/metaverse 를 임시 사본으로 (Apache 2.4 + .htaccess 포함, --docroot 로 다른 폴더)
node tests/admin-lock.mjs              # 관리자 센터 잠금 (2단계 인증·허용 주소·.htaccess)
php tests/security-unit.php && php tests/security-data-unit.php && php tests/admin-unit.php   # 보안 단위 시험
node tools/sql-audit.mjs    # 변수로 만든 SQL 찾기 (검토 안 된 것이 있으면 실패)
node tools/secret-scan.mjs  # 비밀 값 찾기 (--history: 깃 기록 전체)
node tools/exposure-audit.mjs --apache   # 웹에서 열리면 안 되는 파일이 열리는지
```

- **구조**: `3D = Three.js` / `UI = HTML+CSS` / `데이터 = G.data(콘텐츠)·G.state(저장)` / `서버 = PHP REST API`
- `src/game/NN-*.js` 조각(fragment)들을 빌드가 한 파일로 합칩니다. 콘텐츠(작물·퀘스트·발효 레시피)는 `01-data.js`의 데이터만 추가하면 늘어납니다.
- 모듈 간 약속(API·이벤트·저장 구조)은 `docs/CONTRACT.md`, 전체 설계는 `docs/ARCHITECTURE.md`, **인수인계 문서는 `docs/HANDOVER.md`** 를 보세요.
- 체험관 안에서 **F9**(또는 주소 뒤 `?dev=1`)를 누르면 개발자 점검·인수인계 센터가 열립니다 — 위 문서들도 그 안에서 바로 읽을 수 있습니다.
- 3D 모델 교체: `G.data.modelOverrides = { B_HALL: 'assets/models/hall.glb' }` 처럼 GLB 경로를 지정하면(웹서버 실행 시) 절차적 블록아웃 모델 대신 GLB를 불러옵니다.
