# 전통발효체험관 메타버스

한국 전통발효문화와 농업체험을 3D로 탐험하며 배우는 **브라우저 메타버스 게임**입니다.
설치 없이 **HTML 파일 하나**로 실행됩니다 (Three.js 3D 엔진 내장, 인터넷 연결 불필요).

> **용어 풀이**
> - **메타버스**: 여러 사람이 아바타로 접속해 함께 돌아다니는 3D 가상 공간
> - **Three.js**: 웹브라우저에서 3D 그래픽을 그려 주는 자바스크립트 라이브러리 (WebGL 사용)
> - **WebGL**: 브라우저가 그래픽카드(GPU)로 3D를 그리게 해 주는 표준 기술
> - **단일 파일(Single-file) 빌드**: 코드·스타일·3D 엔진·글꼴을 HTML 한 파일에 모두 넣은 형태

## 1. 바로 실행하기

| 방법 | 하는 일 | 저장 위치 |
|---|---|---|
| **A. 파일 더블클릭** | `전통발효체험관.html` (또는 `metaverse/index.html`)을 Chrome·Edge·Firefox·Safari로 열기 | 이 브라우저(localStorage) |
| **B. PHP 서버 모드** | `metaverse/` 폴더를 XAMPP `htdocs`에 복사 → `http://localhost/metaverse/` 접속 | 서버 DB (회원가입·서버 저장·실시간 채팅/접속자) |

- **localStorage**: 브라우저 안에 데이터를 저장하는 공간. 같은 브라우저로 다시 열면 이어서 할 수 있습니다.
- B 방식은 `metaverse/README-SERVER.md`를 참고하세요 (기본 SQLite, 설정 시 MySQL/MariaDB).

## 4. 주요 기능

- **3D 월드**: 산·계곡·강, 현대식 유리+한옥 지붕 체험관, 한옥·초가집·정자, 나선형 장독대, 3×2 작물밭, 허브정원, 휴식정원
- **아바타**: 귀여운 3등신 캐릭터, 헤어·옷·한복·가방·소품 꾸미기
- **NPC 5명 + 대화 분기**: 발효마스터·산골농부·전통사랑·장독지기·안내원
- **퀘스트**: 튜토리얼 메인 퀘스트 + 탐험·농사·발효·교육·사진·소통 퀘스트 (금빛 표식 안내)
- **농사**: 씨앗 심기 → 물 주기 → 성장(성장률·수분·건강) → 수확, 작물 10종
- **장독 발효**: 계정당 1개 배정되는 빛나는 내 장독, 된장·간장·고추장·김치·식초 (온도·습도·위생 → 품질)
- **교육·퀴즈**: 9개 주제, 3D 모형 뷰어, 정답 시 경험치·교육 포인트
- **작업일지·도감·업적·칭호·레벨·상점**
- **미니맵·전체 지도·빠른 이동**, **날씨(맑음/흐림/비/안개/눈)와 낮·밤**, **사진 모드**(필터·프레임·PNG 저장)
- **채팅·이모지·제스처·음성 입력**, 다른 체험객(로컬 모드는 시뮬레이션, 서버 모드는 실제 접속자)
- **설정**: 그래픽 품질 자동 조절, 효과 연출(끔/은은하게/풍성하게), 소리, 감도, UI 크기, 고대비·큰 글자 등 접근성
- **🏺 마스코트 '옹이'**: 플레이어를 따라다니는 3D 장독 요정 — 상황별 힌트, 표정 7종, 쓰다듬기·옷 갈아입히기·이름 바꾸기
- **🔔 오늘의 체험 허브(N)**: 7일 출석 도장, 매일 바뀌는 미션 3개+보너스, 알림함, 캔버스 수료증(PNG 저장·인쇄), 랭킹, 내 마당 꾸미기
- **✨ 모션 그래픽**: 레벨 업 축하 연출, 완료 도장, 코인이 HUD로 날아가는 효과, 3D 파티클(폭죽·하트·별·꽃잎)
- **👶 쉬운 모드**: 큰 그림 버튼·읽어주기·"다음 할 일" 카드·그림으로 고르기·보호자 확인·쉬는 시간 알림 (기본값, 보통 모드로 전환 가능)
- **🛠️ 개발자 점검·인수인계 센터(F9)**: 건강 점수, 시스템/WebGL 점검 + **🖥️ GPU 안전**(검은 사각형 방지·NaN 주입 테스트), **👶 쉬운 모드 점검**(누르기 크기·글자 입력칸·겹침·대비·읽어주기, 주요 화면 차례로 점검), 모듈 상태, 데이터 검증기, 저장 데이터 뷰어, 서버 점검, 자가 테스트 70종+, 디버그 도구, 소스 구조·이벤트 지도, 문서, 인수인계 체크리스트, 진단 보고서 다운로드

> 게임 속 발효·재배 수치는 **교육용 가상 시뮬레이션**이며 실제 제조법·효과를 보장하지 않습니다.
> 레벨 칭호는 게임 내 칭호이며 실제 자격과 무관합니다.

## 5. 보안 요약

- **CSP(콘텐츠 보안 정책)**: 빌드가 인라인 스크립트의 해시를 계산해 허용 — 외부 스크립트·eval·인라인 이벤트 금지 (XSS 방어)
- 사용자 입력은 모두 이스케이프 또는 `textContent`로 표시, 채팅 욕설 필터(띄어쓰기·자모·l33t 우회 정규화)·도배 방지
- **어린이 개인정보 보호**: 채팅의 전화번호·이메일·주소·학교·링크를 🔒 로 가림(게임 + 서버 저장 전), 개인정보 같은 닉네임 거부, 쉬운 모드는 글자 입력 없음, 어른 화면 앞 보호자 확인
- 로컬 계정 비밀번호: **PBKDF2-SHA256 60만 회** + 무작위 솔트 (비밀번호 원문은 저장하지 않음), 로그인 실패 시 잠금
- 서버 모드: Argon2id 비밀번호, CSRF 토큰·Origin 검사, 세션 고정 방지, 무차별 대입 잠금, **저장 데이터 치팅 검증**(보상표·서버 시간 기준, 하루 1회 보상 장부), 업로드 이미지 재인코딩
- 자세한 내용: `server/README-SERVER.md`, `docs/HANDOVER.md`

> **용어 풀이** — *CSRF*: 다른 사이트가 내 로그인 상태를 몰래 이용해 요청을 보내는 공격 · *PBKDF2/Argon2id*: 비밀번호를 일부러 느리게 여러 번 해시해 추측을 어렵게 만드는 방식 · *솔트*: 같은 비밀번호라도 저장값이 달라지도록 섞는 무작위 값

## 6. 개발자용

```bash
npm install                 # three, esbuild, playwright, pretendard (빌드·테스트 도구)
npm run build               # src/ → dist/metaverse/index.html (+ PHP 서버 파일)
node tools/smoke.mjs        # 헤드리스 브라우저 자동 실행 테스트 (오류·스크린샷)
node tests/server-e2e.mjs   # 서버 보안·기능 E2E 46단계 (php -S 자동 실행, 개인정보 가림 벡터·DB 스팸 키 포함)
node tools/kid-audit.mjs    # 👶 쉬운 모드 화면 자동 점검 (치명 문제가 있으면 실패) — --mobile · --both · --out 파일
npm run package             # release/fermentation-metaverse.zip
npm run serve:php           # PHP 내장 서버로 서버 모드 실행 (http://127.0.0.1:8080)
```

- **구조**: `3D = Three.js` / `UI = HTML+CSS` / `데이터 = G.data(콘텐츠)·G.state(저장)` / `서버 = PHP REST API`
- `src/game/NN-*.js` 조각(fragment)들을 빌드가 한 파일로 합칩니다. 콘텐츠(작물·퀘스트·발효 레시피)는 `01-data.js`의 데이터만 추가하면 늘어납니다.
- 모듈 간 약속(API·이벤트·저장 구조)은 `docs/CONTRACT.md`, 전체 설계는 `docs/ARCHITECTURE.md`, **인수인계 문서는 `docs/HANDOVER.md`** 를 보세요.
- 게임 안에서 **F9**(또는 주소 뒤 `?dev=1`)를 누르면 개발자 점검·인수인계 센터가 열립니다 — 위 문서들도 그 안에서 바로 읽을 수 있습니다.
- 3D 모델 교체: `G.data.modelOverrides = { B_HALL: 'assets/models/hall.glb' }` 처럼 GLB 경로를 지정하면(웹서버 실행 시) 절차적 블록아웃 모델 대신 GLB를 불러옵니다.
